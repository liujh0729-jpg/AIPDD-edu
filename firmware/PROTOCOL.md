# 智能硬件（ESP32）主机 ↔ 设备 协议契约 v1

> 对应需求：`需求/智能硬件模式-需求方案.md` FR-10.7 / FR-10.10
> 主机侧实现：`app/src/main/hardware.js`（HardwareManager）
> 本文件是主机与设备固件的**唯一接口契约**；任一侧改动须同步本文件与另一侧。

## 0. 总则与硬约束
- **拓扑**：主机（电脑 App）为客户端与编排大脑；**设备为 WebSocket 服务端**，主机主动连接设备。会话状态以主机为准，设备是"薄 IO + 执行器"。
- **边界**：仅局域网（同 WiFi 子网）；**不经公网/云端中转**；**设备侧绝不调用任何大模型网关**（VLM/LLM/STT/TTS 全在主机，经 F6 网关、仅用户动作触发，严禁自动计费）。
- **鉴权**：一次性共享 Token（主机存本机 0600，键名 `hw:<deviceId>`）；**固件不得内置真实 token/密钥**，配网时一次性注入。
- **协议版本**：`proto = 1`。控制帧为 UTF-8 JSON 文本；媒体帧为二进制。

## 1. 传输
- WebSocket：主机连 `ws://<设备IP>:<ws端口>/`（默认 `80`）。
- 文本帧 = 控制信令（JSON，含 `t` 字段）。
- 二进制帧 = 媒体，**首字节为类型标签**：

  | 标签 | 方向 | 载荷 |
  |------|------|------|
  | `0x01` | 上行 | 图像：一帧完整 JPEG（建议宽 640~1280） |
  | `0x02` | 上行 | 音频：PCM **16kHz / 16bit / 单声道** 分块（裸 PCM，无头） |
  | `0x03` | 下行 | 音频：TTS 播放数据流（WAV，PCM16/单声道；见 §5） |

## 2. 发现（FR-10.1）
设备通过 **UDP 广播信标** 声明自己；主机监听 `discoveryPort`（默认 **48000/udp**）。

- 信标 JSON（设备 → 广播 `255.255.255.255:48000`，周期 ≤ 2s）：
  ```json
  { "magic": "dt-esp32", "id": "esp32-abc123", "name": "书桌家教", "ip": "192.168.1.50",
    "port": 80, "caps": { "cam": true, "mic": true, "spk": true }, "proto": 1 }
  ```
- 查询（主机 → 广播 `255.255.255.255:48000`，点"扫描"时）：
  ```json
  { "magic": "dt-esp32", "q": "discover", "proto": 1 }
  ```
  设备收到后立即补发一条信标（单播回应答源地址亦可）。
- 主机对超 `7s` 未见信标的**非活动**设备自动从列表移除。
- **手动兜底**：发现失败时，主机可用"输入设备 IP + 端口"直连（等价于跳过信标）。

## 3. 握手与鉴权（FR-10.2）
1. 主机连上 WebSocket 后，**设备应主动上报 hello**：
   ```json
   { "t": "hello", "id": "esp32-abc123", "name": "书桌家教", "fw": "1.0.0", "proto": 1,
     "caps": { "cam": true, "mic": true, "spk": true }, "audio": { "rate": 16000, "ch": 1, "bits": 16 } }
   ```
2. 若主机在 **2s** 内未收到 hello，会发 `{ "t": "ping" }`；设备应回 `{ "t": "pong" }` 并随后补发 hello。
3. 主机收到 hello 后发起鉴权：`{ "t": "auth", "token": "<共享token>" }`。
4. 设备校验：
   - 通过 → `{ "t": "auth_ok" }`（主机进入 `connected`）
   - 失败 → `{ "t": "auth_fail" }`（主机断开并提示）
5. 鉴权后主机可下发 `config`（下行播放参数等，可选）。

## 4. 流控与上行（FR-10.3 / FR-10.4）
- 主机 → 设备：`{ "t": "stream", "audio": true|false, "image": true|false }`。
- 设备行为：
  - `image:true` → 周期回传 `0x01` JPEG 帧（帧率/间隔由主机抓帧策略决定，见下）。
  - `audio:true` → **持续回传 `0x02` 裸 PCM 分块**（每块建议 20~100ms，即 320~1600 采样）。
  - `false` → 停止对应上行（省电/省带宽；idle 态）。
- **唤醒/VAD 在主机本地跑**：设备只需原样回传连续 PCM，**不做唤醒词、不做网络请求**。主机用能量门限分段后，仅在检出的语音段才走 STT/网关（满足"仅用户动作/说话触发"）。

## 5. 下行 TTS 播放（FR-10.6 路径二 / FR-10.10c）
主机把回复渲染为 **WAV（PCM16/单声道）** 后下放：
```
{ "t": "play_begin", "seq": <n>, "format": "wav", "bytes": <总字节> }
<二进制 0x03 分块……>          // 每块 ≤ 4096 字节（首字节 0x03）
{ "t": "play_end", "seq": <n> }
```
- 设备：从 WAV 头解析采样率，将 PCM 写入 I2S 功放播放。
- **半双工（强制）**：`play_begin`~`play_end` 期间，设备**必须暂停麦克风上行**（避免喇叭声被自己麦克风拾回造成自问自答）。产品级再上 AEC。

## 6. 远程控制（FR-10.10）
主机 → 设备：`{ "t": "cmd", "seq": <n>, "action": "<动作>", "arg": <参数> }`；设备执行后回 `{ "t": "ack", "seq": <n>, "code": 0 }`（`code!=0` 表失败）。超时 4s 主机按失败处理。

| action | arg | 设备行为 |
|------|------|------|
| `session` | `start`/`stop`/`pause`/`resume` | 进入/退出采集工作态（等价开关 audio+image 流） |
| `capture` | `{ "hd": true }` | 立即回传一帧高清 `0x01` |
| `volume` | `0`..`100` | 设置喇叭音量 |
| `mute` | `true`/`false` | 静音 |
| `led` | `on`/`off`/`state:<名>` | 状态灯 |
| `cue` | `ready` | 播放"我在听"提示音（唤醒/响应反馈，FR-2.1a） |
| `speak` | `<text>` | 可选：设备本地 TTS（一般不用；主路径是主机 `play_begin` 下放） |
| `power` | `sleep`/`wake` | 休眠/唤醒 |
| `reboot` | — | 重启 |
| `info` | — | 回一条 `state`（fw/rssi/heap/音量等） |

## 7. 设备主动上报（异步）
- `{ "t": "state", "rssi": -55, "fw": "1.0.0", "heap": 123456, "playing": false }`（`info` 或周期/事件触发）
- `{ "t": "error", "code": "<码>", "msg": "<描述>" }`

## 8. 状态机（主机侧）
`disconnected → connecting →（收到 hello）pairing →（auth_ok）connected →（stream 开）working`；异常/断连回 `disconnected`，`autoReconnect` 下指数退避重连（上限 6 次）。

## 9. 安全清单（设备侧自查）
- [ ] 不硬编码真实 token/密钥；token 由配网注入，内存校验。
- [ ] 仅监听局域网；拒绝公网来源连接（可选 token 二次校验）。
- [ ] 绝不在固件内调用任何模型/计费接口。
- [ ] 播放期暂停麦克风上行（半双工）。
- [ ] 日志不含明文 token。

## 10. 与主机实现的对齐点（供固件作者核对）
- 主机对**文本帧**按 `t` 路由：`hello/auth_ok/auth_fail/ack/state/error/pong`。
- 主机对**二进制帧**按首字节 `0x01→frame 事件`、`0x02→音频分段`；`0x03` 仅主机下发，设备不会向主机发 `0x03`。
- 主机上行音频分段参数（默认）：能量 RMS 门限 `600`、尾静音 `700ms` 收束、单段上限 `8000ms`、最短有效 `~0.3s`（过短丢弃）。设备无需实现，仅需持续回传 PCM。
